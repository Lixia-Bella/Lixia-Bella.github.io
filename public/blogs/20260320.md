# 阳光小站 JavaScript ES6+ 核心语法速览

> 作者：Bella ｜ 日期：2026-03-20

ES6 之后，JavaScript 在语法表达力与工程化能力上都发生了明显变化。模块化、解构赋值、模板字符串、箭头函数、Promise、`async/await` 等能力，已经成为现代前端开发的基础。本文按“最常见、最常用、最值得优先掌握”的顺序做一份核心语法速览。

## 一、`let` 与 `const`

在现代 JavaScript 中，优先使用 `const`，只有在变量需要被重新赋值时再使用 `let`。

```js
const siteName = '阳光小站';
let currentPage = 'home';
```

两者都具有块级作用域，能避免 `var` 带来的变量提升和作用域混乱问题。

### 什么时候用 `const`

- 配置项
- 函数
- 不会重新赋值的对象引用
- 常量值

### 什么时候用 `let`

- 循环计数器
- 状态切换值
- 需要重新赋值的中间变量

## 二、模板字符串

模板字符串使用反引号包裹，支持变量插值和多行字符串，比传统字符串拼接更直观：

```js
const title = 'JavaScript ES6+ 核心语法速览';
const message = `当前文章标题：${title}`;
```

当字符串中包含变量、HTML 片段或换行内容时，模板字符串几乎是默认选择。

## 三、解构赋值

解构赋值可以从数组或对象中快速提取值，使代码更简洁。

### 数组解构

```js
const colors = ['pink', 'lavender', 'mint'];
const [primary, secondary] = colors;
```

### 对象解构

```js
const user = { name: 'Bella', role: 'developer' };
const { name, role } = user;
```

在函数参数中使用对象解构也非常常见：

```js
function renderCard({ title, summary }) {
  console.log(title, summary);
}
```

## 四、展开运算符与剩余参数

### 展开运算符 `...`

用于展开数组、对象或函数参数：

```js
const a = [1, 2];
const b = [...a, 3, 4];

const profile = { name: 'Bella' };
const fullProfile = { ...profile, city: 'Shenzhen' };
```

它非常适合做不可变数据更新，这也是 React 中常见的写法。

### 剩余参数

用于接收不定数量的参数：

```js
function sum(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}
```

## 五、箭头函数

箭头函数让函数表达更简洁：

```js
const double = (n) => n * 2;
```

如果只有一个参数，可以省略括号；如果函数体只有一个表达式，可以省略 `return`。但需要注意，箭头函数**没有自己的 `this`**，因此不适合所有场景，尤其是在对象方法或需要动态 `this` 的场合。

## 六、默认参数

函数可以直接给参数提供默认值：

```js
function greet(name = '朋友') {
  return `你好，${name}`;
}
```

这比过去的“逻辑或兜底”写法更清晰，也更安全。

## 七、对象字面量增强

ES6 允许对象写法更简洁：

```js
const name = 'Bella';
const age = 20;

const user = {
  name,
  age,
  sayHi() {
    console.log('Hi');
  },
};
```

当变量名与属性名一致时，可以直接省略一层重复书写。

## 八、Promise

Promise 用于处理异步操作结果，能解决层层嵌套回调的问题。

```js
fetch('/api/posts')
  .then((res) => res.json())
  .then((data) => {
    console.log(data);
  })
  .catch((err) => {
    console.error(err);
  });
```

理解 Promise 的三个状态很重要：

- `pending`
- `fulfilled`
- `rejected`

## 九、`async / await`

`async / await` 是建立在 Promise 之上的更直观写法：

```js
async function loadPosts() {
  try {
    const res = await fetch('/api/posts');
    const data = await res.json();
    return data;
  } catch (error) {
    console.error(error);
    return [];
  }
}
```

它让异步代码更像同步流程，尤其适合连续步骤较多的场景。

## 十、模块化 `import / export`

现代前端项目基本都使用 ES Module：

```js
export const siteName = '阳光小站';

export function formatDate(date) {
  return date;
}
```

在其他文件中引入：

```js
import { siteName, formatDate } from './utils.js';
```

模块化的好处包括：

- 职责拆分清晰
- 文件之间边界更明确
- 便于复用与维护

## 十一、常见的 ES6+ 学习优先级

如果你刚接触现代 JavaScript，我建议优先掌握：

1. `let` / `const`
2. 模板字符串
3. 解构赋值
4. 展开运算符
5. 箭头函数
6. Promise
7. `async / await`
8. `import / export`

这几项掌握后，阅读 React、Vue、Node.js 代码会顺畅很多。

## 十二、总结

ES6+ 不是一堆零散语法点，而是一套更现代的 JavaScript 编程方式。掌握它们的关键不在于死记，而在于理解“为什么这种写法更适合现代开发”：更清晰、更模块化、更适合异步流程，也更适合组件化与工程化场景。
