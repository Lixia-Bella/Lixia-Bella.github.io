# 阳光小站 数组高阶方法实战：map、filter、reduce

> 作者：Bella ｜ 日期：2026-03-20

数组高阶方法是 JavaScript 中最值得重点掌握的一类 API。它们能让我们用更声明式的方式处理数据，而不是一上来就写循环、临时变量和层层 `if`。本文围绕 `map`、`filter`、`reduce`，再补充 `find`、`some`、`every` 的典型应用场景。

## 一、什么是高阶方法

所谓高阶方法，本质上是“接收函数作为参数”的数组方法。它们通常不会直接修改原数组，而是返回一个新的结果，这种风格在现代前端开发里非常常见。

最常见的好处有：

- 代码更简洁
- 意图更明确
- 更容易组合
- 更适合不可变数据更新

## 二、`map`：映射，适合“一对一转换”

`map` 会遍历数组，并返回一个**等长的新数组**。它最适合把一种数据结构转换成另一种结构。

```js
const prices = [19, 29, 39];
const discountPrices = prices.map((price) => price * 0.9);
```

### 典型场景

- 给商品价格打折
- 把接口数据转换成页面展示数据
- 在 React 中渲染列表

例如把文章数据转成卡片标题：

```js
const posts = [
  { id: 1, title: 'HTML5 语义化标签与页面结构设计' },
  { id: 2, title: 'Flexbox 与 Grid 布局完全指南' },
];

const titles = posts.map((post) => post.title);
```

### `map` 的关键判断

如果你想问自己“我是不是该用 `map`”，一个简单判断方法是：

> 我是否想把数组中的每一项都处理一遍，并返回一个对应的新结果？

如果答案是“是”，那大概率就是 `map`。

## 三、`filter`：筛选，适合“保留符合条件的项”

`filter` 会返回一个由符合条件元素组成的新数组，长度可能变短。

```js
const scores = [58, 76, 91, 43, 88];
const passed = scores.filter((score) => score >= 60);
```

### 典型场景

- 搜索结果过滤
- 标签分类筛选
- 只保留启用状态的数据

例如筛选前端标签文章：

```js
const posts = [
  { title: 'Flexbox', tags: ['CSS'] },
  { title: 'ES6+', tags: ['JavaScript'] },
];

const cssPosts = posts.filter((post) => post.tags.includes('CSS'));
```

### 常见误区

有些人会把 `filter` 当作“在循环里顺手做点事”的工具。但如果你并不需要返回筛选后的新数组，只是想遍历，那应该考虑 `forEach` 或其他更合适的方法。

## 四、`reduce`：归约，适合“把数组压缩成一个结果”

`reduce` 的威力很大，但也最容易让初学者困惑。它的本质是：**把数组里的多项数据，累积成一个最终结果**。

```js
const nums = [1, 2, 3, 4];
const sum = nums.reduce((total, current) => total + current, 0);
```

这里的 `0` 是初始值，`total` 是累加器。

### 典型场景

- 求和、求平均值
- 统计次数
- 数组转对象
- 多字段聚合计算

例如统计标签出现次数：

```js
const tags = ['CSS', 'JavaScript', 'CSS', 'HTML'];

const tagCount = tags.reduce((acc, tag) => {
  acc[tag] = (acc[tag] || 0) + 1;
  return acc;
}, {});
```

执行后会得到：

```js
{
  CSS: 2,
  JavaScript: 1,
  HTML: 1
}
```

### 什么时候不要强行用 `reduce`

虽然 `reduce` 很强，但不是所有问题都值得用它。如果一个需求用 `map` 或 `filter` 能清楚表达，就没必要为了“显得高级”强行写成 `reduce`。

## 五、`find`：找到第一个匹配项

`find` 返回第一个满足条件的元素，找不到则返回 `undefined`。

```js
const users = [
  { id: 1, name: 'Bella' },
  { id: 2, name: 'Luna' },
];

const user = users.find((item) => item.id === 2);
```

适合：

- 根据 id 查找详情对象
- 根据 slug 查找某篇文章
- 在配置数组中找到某个指定项

## 六、`some` 与 `every`

### `some`

只要有一项满足条件，就返回 `true`。

```js
const hasNegative = [3, 8, -1, 5].some((n) => n < 0);
```

### `every`

只有所有项都满足条件，才返回 `true`。

```js
const allPassed = [76, 88, 91].every((n) => n >= 60);
```

这两个方法很适合做校验逻辑。

## 七、链式调用的优势

数组高阶方法的魅力之一是可以自然串联：

```js
const result = products
  .filter((item) => item.inStock)
  .map((item) => ({
    name: item.name,
    total: item.price * item.count,
  }));
```

这样的代码读起来非常像“先筛选，再转换”，逻辑顺序很自然。

## 八、一个实际案例：商品列表处理

假设我们有如下商品数组：

```js
const products = [
  { name: '键盘', price: 199, count: 2, inStock: true },
  { name: '鼠标', price: 99, count: 1, inStock: false },
  { name: '耳机', price: 299, count: 1, inStock: true },
];
```

### 只保留有库存商品

```js
const available = products.filter((item) => item.inStock);
```

### 转成展示层数据

```js
const cardData = available.map((item) => ({
  title: item.name,
  totalPrice: item.price * item.count,
}));
```

### 统计总金额

```js
const totalAmount = available.reduce(
  (sum, item) => sum + item.price * item.count,
  0
);
```

这就是高阶方法在真实业务里的典型组合。

## 九、一个简单选择口诀

我自己经常用下面这个口诀做快速判断：

- **要变形**：用 `map`
- **要筛选**：用 `filter`
- **要汇总**：用 `reduce`
- **要找一个**：用 `find`
- **判断是否存在**：用 `some`
- **判断是否全部满足**：用 `every`

## 十、总结

数组高阶方法的重点不在于“记住 API 名字”，而在于建立数据处理思维。只要你能先想清楚需求到底是“变形”“筛选”还是“汇总”，就很容易选对方法。掌握这些 API 之后，现代 JavaScript 代码会明显更简洁，也更接近真实项目的写法。
